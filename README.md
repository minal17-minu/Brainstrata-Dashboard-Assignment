# BrainStrata Analytics Dashboard — UI Design Task

Internshala Design Submission | 2026

## What's Inside
- `BrainStrata_Dashboard_Design.pdf` — Full 3-page design submission
- `brainstrata_dashboard.py` — Python code used to generate the PDF

## About the Design
A dark neuro-tech analytics dashboard for BrainStrata featuring:
- Real-time KPI cards (Focus Score, Cognitive Load, Flow Sessions, Team Sync)
- Hourly focus trend line graph
- Cognitive distribution donut chart
- Weekly activity heatmap
- Team flow state monitor for 6 members
- Design rationale & system thinking

## Tools Used
- Python + ReportLab (PDF generation)
- Design system: Dark navy (#0A0E1A) + Mint accent (#6EE7B7)

## Run It Yourself
pip install reportlab
